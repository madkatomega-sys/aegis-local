The tests have passed. Here's a summary of the bug and fix:

## Bug Found

The `chunks` function in `chunks.py` had two issues:

1. **Wrong comparison operator**: `if len(current) > size:` should be `if len(current) >= size:` - this ensures chunks are created immediately when they reach the target size.

2. **Missing leftover items**: After the loop ended, any remaining items in `current` (which would be fewer than `size`) weren't being added to the result.

## Fix Applied

Changed the function from:
```python
def chunks(items, size):
    result = []
    current = []
    for item in items:
        current.append(item)
        if len(current) > size:  # Wrong: only adds when > size
            result.append(current)
            current = []
    return result  # Missing: leftover items not added
```

To:
```python
def chunks(items, size):
    result = []
    current = []
    for item in items:
        current.append(item)
        if len(current) >= size:  # Fixed: adds when >= size
            result.append(current)
            current = []
    if current:  # Added: add remaining items
        result.append(current)
    return result
```

Both tests now pass.
