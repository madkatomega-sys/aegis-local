## Bugs Found and Fixed

### 1. `money.py` - Floating point rounding issue
**Bug**: The `cents()` function used `int(amount * 100)` which truncates instead of rounding.
- Due to floating-point representation, `19.99 * 100` evaluates to `1998.9999...`
- `int()` truncates this to `1998` instead of the expected `1999`

**Fix**: Changed `int(amount * 100)` to `round(amount * 100)`

### 2. `cart.py` - Missing quantity multiplication
**Bug**: The `total()` function wasn't multiplying by the quantity at all.
- It was doing `result += cents(price)` for each line
- Should be `result += cents(price) * _quantity`

**Fix**: Added `* _quantity` to multiply by the quantity
