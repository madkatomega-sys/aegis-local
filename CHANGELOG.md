### Added

- Project plan, threat model, platform guide, and model loadout guide.
- README, NOTICE, contributing guide (DCO), code of conduct, and security policy.
- Repository layout: launcher, Compose stack, configuration schemas, GPU profiles.
- Guard proxy core: canonical call hashing, loop and oscillation breaker, budgets, session taint
  tracking, approval holds, SQLite audit ledger.
- Model router core: alias and task-based tier selection with token caps.
- Sandbox worker skeletons for code, math and physics, and writing.
- OpenCode configuration, least-privilege agents, and status plugin.
- Unit tests and CI.
- Governance: roles, CODEOWNERS, approved contributor list with a `contributor-approved` gate,
  contributor access request template, and branch and tag rulesets.
