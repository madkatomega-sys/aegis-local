# The Universal Computer: reading notes

These are sample notes so the writing auditor has something to index on first run. Point
AEGIS_VAULT_PATH at your own notes folder to replace them.

## Leibniz

Leibniz imagined a universal formal language paired with a calculus of reasoning, so that
disputes could be settled by calculation instead of argument.

## Turing, 1936

Turing described a single machine that can imitate any other machine when that machine's rules
are written on its tape as data. Instructions and data share the same tape.

## Limits

Turing also showed that no general procedure can decide whether an arbitrary program halts.
Gödel showed that a consistent formal system rich enough for arithmetic contains true statements
it cannot prove.
